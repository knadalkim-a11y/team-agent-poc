# EES Assistant 처음 사용하기 — 팀 시연 준비본

팀 시연을 위한 안내입니다. 아래 업무는 현재 연결 기능의 예시이며 일반 질문·글쓰기·내용 정리에도 사용할 수 있습니다. 실제 첫 화면 적용과 안내 전달 여부는 담당자가 확인합니다.

전달받은 사내 주소에서 본인 계정으로 로그인하고, 새 대화에서 **EES Assistant**를 선택하세요. 표시 이름 변경 전에는 **EES 통합 Assistant**로 보일 수 있습니다. 원하는 일을 직접 적으면 됩니다.

## 현재 연결 기능의 사용 예시

| 업무 | 이렇게 시작하세요 |
|---|---|
| 시스템별 Jira 이슈 비교 | “시스템별 Jira 이슈 현황 보여줘.” |
| Confluence 문서 찾기 | 찾을 주제나 문서 제목을 함께 적으세요. 결과에서 필요한 문서의 내용과 원문을 요청할 수 있습니다. |
| 사내 GitHub의 열린 PR 확인 | “연결된 GitHub 저장소의 열린 PR 목록을 보여줘”라고 요청하세요. 대상이 여러 개면 Assistant가 물어봅니다. 목록에서 PR 하나를 골라 본문 요약과 원문을 요청할 수 있습니다. |
| 업무 내용 정리 | 정리할 내용을 보내고 핵심 내용·해야 할 일 등 원하는 형식을 말하세요. |

대상이나 조건이 부족하면 Assistant가 물어봅니다. GitHub는 현재 PR 목록과 본문을 확인하며 코드 검토나 리뷰 승인 상태 조회는 지원하지 않습니다.

## 내 계정 연결하기

문서·이슈·PR 조회에는 **사용할 서비스의 본인 개인 토큰(PAT)**이 필요합니다. 이미 등록했다면 다시 입력하지 않습니다. 업무 내용 정리에는 이 토큰이 필요하지 않습니다.

새 대화의 **통합 → 도구 → 해당 항목 옆 개인 설정(밸브)**을 열어 `PAT`에 입력하고 저장하세요.

| 사용할 서비스 | 개인 설정을 열 항목 |
|---|---|
| Jira | EES Jira Read |
| Confluence | EES Confluence Read |
| GitHub | EES GitHub Read |

토큰은 채팅에 붙여 넣거나 다른 사람과 공유하지 마세요. 설정 항목이 보이지 않거나 토큰이 없다면 담당자에게 해당 서비스 연결을 문의하세요.

## 조회 예시: 시스템별 이슈 현황

1. **“시스템별 Jira 이슈 현황 보여줘”**라고 요청합니다.
2. 전체·미완료 건수를 비교하고 관심 있는 시스템을 선택해 받은 이슈 목록을 살펴봅니다.
3. 관심 이슈의 **원문**을 열어 Jira에서 확인합니다.

화면에서 시스템·상태를 고르는 것은 **이미 받은 목록을 좁히는 동작**입니다. 해당 시스템의 이슈를 새로 조회하려면 화면에 표시된 프로젝트 키로 “이 프로젝트 이슈를 새로 조회해줘”라고 요청하세요. 저장된 대화의 화면은 당시 조회 결과이므로 최신 현황은 다시 질문합니다.

결과는 본인 계정으로 볼 수 있는 범위입니다. 조회 실패나 미확인 표시는 0건을 뜻하지 않습니다.

## 막히면

인증 실패는 해당 서비스의 개인 토큰을, 조회 제한은 요청 대상과 원 시스템의 본인 접근 권한을 확인하세요. 해결되지 않으면 **어떤 일을 하려 했는지와 오류 문구**를 담당자에게 알려주세요. 토큰이나 실제 업무 본문을 함께 보내지 마세요.
