## 1. 범위와 용어

- **공용 도구**: 업무에서 쓰는 동작 하나입니다. Open WebUI 도구 파일 안의 함수 하나에 대응합니다. 관리 시스템과 상관없이 목록은 하나입니다.
- **1단계-1 대상**: 기본 제공 Confluence `search_pages`(페이지 찾기) · `get_page`(페이지 읽기). 나머지 기본 제공 함수 8개(Jira 6 · GitHub 2)는 ‘준비 중’으로 보이기만 합니다.
- **버전**: 관리자가 확인한 ‘참조 · 입력 형식 · 결과 형식’ 조합의 번호입니다. v1부터 셉니다.
- **참조**: 설치된 도구 ID · 함수 · 코드 지문 · 입력 형식 지문 · 연결 설정 지문 · 실행 환경 · 읽기 승인 번호입니다. 관리자만 봅니다.
- **회차 고정**: 회차가 시작될 때 그 회차가 쓸 도구의 버전과 참조를 기록한 것입니다.
- **이전 방식 도구**: 관리 시스템별 기존 도구 계약입니다. 이 문서를 적용하지 않고 지금 동작을 유지합니다.
- **제외**: 사내 등록 도구 · 새 버전 만들기 · 되돌리기 · 코드 보기(2단계, B10-3·4·8), 한 작업 안의 이어 붙이기와 절차 구조(1단계-2, B10-6·7), 변경 도구 실행, 전용 계정, 목록 항목마다 반복 실행.

## 3. 상태

판정은 목록 · 작업에서 고르기 · 게시 · 회차 시작 · 실행 호출이 모두 같은 발견 결과를 씁니다(ST-STATE-1). 여러 상태에 해당하면 위에서부터 먼저 맞는 것을 씁니다.

| 상태 | 판정 조건 | 고르기 · 새 회차 | 진행 중 회차의 다음 호출 | 관리자가 할 수 있는 것 |
|---|---|---|---|---|
| 준비 중 | 1단계-1 대상이 아닌 함수 | 안 됨 | 멈춤 | 없음(확인 거부) |
| 못 씀 | 설치 · 원본 · 권한 · 설정 판정 실패. 원인은 아래 목록 | 안 됨 | 멈춤(원인 안내) | Open WebUI 쪽에서 원인 해결. 이 화면의 확인 · 그룹 변경은 거부 |
| 사용 중지 | 관리자가 중지함 | 안 됨 | 멈춤 | 다시 켜기(지금 참조가 확인본과 같을 때만) |
| 도구 확인 필요 | 확인 뒤 참조 · 입력 형식 · 결과 형식 중 하나가 바뀜, 또는 읽기 승인이 유효하지 않음 | 안 됨 | 멈춤 | 입력·결과 확인 |
| 확인 전 | 설치 · 원본 정상, 확인 기록 없음 | 안 됨 | 해당 없음 | 입력·결과 확인 |
| 쓸 수 있음 | 확인 기록이 있고 지금 참조 · 입력 · 결과가 확인본과 같음 | 됨(그룹 안) | 계속 | 그룹 · 담당 변경, 사용 중지 |

‘못 씀’의 원인: 미설치 · 원본 다름 · 같은 원본 중복 설치 · Open WebUI 읽기 권한 없음 · 연결 설정을 읽을 수 없음 · 지원하지 않는 연결 설정 · 연결 꺼짐 · Open WebUI 도구 기능 꺼짐 · 입력 형식 오류. 원인별 문구는 B10-2 명세 카드에 있습니다.

| ID | 규칙 | 상태 |
|---|---|---|
| ST-STATE-1 | 목록 · 고르기 · 게시 · 회차 시작 · 실행은 같은 판정을 씁니다. 화면과 서버의 판정이 다르면 결함입니다. | 구현 |
| ST-STATE-2 | 사용 중지는 다시 확인해도 유지됩니다. 다시 켜기는 따로 합니다. | 구현 |
| ST-STATE-3 | 같은 원본이 여러 개 설치돼 있어도, 이미 확인한 설치 도구가 그 안에 있으면 그것을 계속 씁니다. 없으면 ‘못 씀(중복 설치)’입니다. | 구현 |
| ST-STATE-4 | 설치 도구는 프로그램이 관리하는 원본 지문으로만 찾습니다. 도구 ID를 가정하지 않습니다. 자동 설치 · 재등록 · 덮어쓰기를 하지 않습니다. | 구현 |
