시안 안내 · 단계와 작업 실행

이 화면

‘배포 산출물 점검’ 절차의 10.27 배포 회차 → 1차 점검 단계입니다. 각 행을 하나의 작업으로 보는 설계 시안이며 작업 12개 중 직접 판정은 3개, 자동 판정은 9개입니다. 확정한 20판을 보존하고 여섯 상태를 대기·실행 중·판정 결과의 세 묶음으로 정리한 별도 21판입니다. 서비스 7개는 판정 완료, 2개는 실행 필요 상태인 예시이며 실제 제품 실행 구조는 바꾸지 않았습니다.

직접 판정과 자동 판정

사람 작업은 ‘판정 기록’에서 누가 언제 무엇을 선택했는지 보고, 사유를 선택적으로 적습니다. 서비스 작업은 ‘판정 근거’에서 실행한 도구를 보고, 도구 하나를 펼쳐 입력·출력·이번 작업의 판정 기준·판정 결과를 확인합니다. 작업과 도구는 각각 하나씩 펼쳐집니다. 도구 실행 완료와 기준 충족 여부는 서로 다릅니다.

실행 방식과 예약

기본은 업무절차의 수시 실행 · 직접 시작이며 자동실행 예약이 없습니다. 확인용 ‘주기 · 예약 예시’는 매주 화요일 09:00 KST와 다음 11.03 화요일 예약을 보여주는 메타데이터 예시입니다. 예약 실행기나 설정 변경 기능은 없습니다.

단계와 작업 실행

단계 제목 옆 ‘이 단계 실행’은 실행 가능한 미실행 서비스 작업만 시작합니다. 완료·제외 작업은 건너뛰고 사람의 판정을 대신하지 않습니다. 개별 ‘다시 실행’은 새 실행 기록을 만들고 이전 입력·출력·결과를 보존합니다. 실행 중에는 이전 결과를 이번 실행 결과로 표시하지 않습니다. 이 시안의 실행은 짧은 화면 전환일 뿐 실제 도구를 호출하지 않습니다.

해 볼 것

  1. 실행이 필요한 작업을 하나 실행하거나 단계 제목 옆 ‘이 단계 실행’ 누르기
  2. 완료된 작업을 다시 실행하고 이전 기록 보기
  3. 직접 판정 작업의 ‘판정 필요’에서 값 고르기
  4. 사람 작업의 ‘판정 기록’에서 사유 적기
  5. 서비스 작업의 ‘판정 근거’에서 도구를 하나씩 펼치기
  6. 판정 결과에서 나머지 승인 항목 펼치기
  7. ‘기록’과 ‘기준’ 탭 보기

아직 정하지 않은 것

사람이 고른 판정을 실제로 저장·최종 확정하는 방법은 아직 정하지 않았습니다. 이 시안에는 확정 버튼이 없고, 판정 선택과 사유 입력만 시험할 수 있습니다. 값을 고르면 판정 결과 묶음으로 이동하며, 저장되거나 판정 완료로 처리되지는 않습니다. 판정 선택·사유·실행 기록은 이 화면에서만 유지되며 초기화하거나 새로 열면 사라집니다.

이 시안은

실제 프로그램의 글꼴 파일과 화면 CSS(색, 크기, 탭·꼬리표·단추 부품)를 그대로 써서 만들었습니다. 왼쪽 메뉴 접기·펼치기와 창 크기에 따른 업무 패널 겹침은 제품 기준을 따릅니다. 도구 이름·입력·출력·지침·시각은 화면 검토를 위한 합성 예시이며 실제 도구 실행 기록이 아닙니다. 문서 존재와 접근 여부의 예시를 보여주며 내용 적정성은 판단하지 않습니다. 여러 도구 결과를 최종 판정으로 합치는 실제 규칙·저장은 아직 정하지 않았습니다. ‘배치 주기 조정’의 첨부는 판정 참고 자료의 표시 예시이며 실제 파일 내용이나 열기·업로드 기능과 연결되지 않습니다. 실제 저장·도구 실행·대화는 되지 않으며, 왼쪽 메뉴 이동과 가운데 대화는 모양만 같습니다. 사내 PC에서 파일이 열리는지도 확인해 주세요.
